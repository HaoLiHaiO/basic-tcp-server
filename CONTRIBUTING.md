# Contributing

This is a small TCP client/server learning project. Keep changes focused and easy to review.

1. Open an issue describing the behaviour you want to change.
2. Make the change in a separate branch.
3. Test both ends locally: start the server, then run the client and check that they communicate as expected.
4. Include the commands you used and the observed result in your pull request.

Do not expose a test server to the public internet unless you have reviewed its security properties. Prefer a local or otherwise isolated environment for experiments.
